### Discussion Summary and Decisions

**1. LLM Backend Tiers & Model Selection**

* **Discussion:** Identifying optimal models for a LangGraph-driven RPG engine across Tiny (<4GB VRAM), Small (6-8GB VRAM), and Midsize (12-16GB VRAM) local hardware tiers, plus premium cloud hosting.
* **Decisions:** * Prioritize models that retain strict JSON tool-calling capabilities even when uncensored (e.g., Qwen 3 Instruct series, Dolphin-Qwen, and abliterated Llama 3.1/3.2 variants).
* Target Magnum v4 72B, Dolphin Llama 3 70B, and Venice Uncensored via OpenRouter for the premium hosted tier.



**2. Licensing & Commercial Distribution**

* **Discussion:** Navigating OSI-approved licenses (Apache 2.0/MIT) versus Acceptable Use Policies (Llama Community License) for Steam/Itch.io and SaaS distribution.
* **Decisions:** * Adopt the **Downloader Pattern** for local game clients, forcing the user to download models at runtime to assume AUP liability.
* Implement a **Bring Your Own Key (BYOK)** system for the cloud service to eliminate developer liability for user-generated API traffic.



**3. Operational Risks & Platform Moderation**

* **Discussion:** Handling Trust & Safety proxy bans from mainstream API providers and legal exposure to regional internet safety laws.
* **Decisions:** * Geo-ban Australia to mitigate immediate regulatory risks.
* Route mature roleplay traffic exclusively through permissive aggregator endpoints (OpenRouter) or IaaS providers (RunPod/Together) rather than mainstream corporate APIs.



**4. MnesOS Guardrail Architecture**

* **Discussion:** Protecting both the runtime game loop and the static cartridge upload system from malicious inputs and broken JSON, without crippling narrative freedom.
* **Decisions:** * Apply the **Strategy Pattern** via LangGraph's `RunnableConfig` to dynamically swap safety strictness between SFW and NSFW game instances.
* **Uploads:** Inject a content classification check into `src/MnesOS/api/cartridges.py` (`create_cartridge_version`) to scan `bot_lore.md` and `yare.yaml` before database insertion.
* **Input:** Place Prompt Guard before `context_retrieval_node` to scrub player intent.
* **Execution:** Wrap the `director_node` LLM tool-calling invocation with Guardrails AI (Python) to guarantee valid YARE schemas.
* **Output:** Place Llama Guard 3 after the `narrator_node` to classify the final rendered prose.
